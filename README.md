# img2litematic

Локальное веб-приложение: превращает изображение в схему Minecraft формата
Litematica (`.litematic`). 2D: 1 пиксель = 1 блок.

## Возможности

- **Масштабирование**: изображение уменьшается (усреднение площади — «средний
  цвет по группе пикселей»), максимальная сторона задаётся в блоках (16–512).
- **Два режима подбора блоков**:
  - *Адаптивный (k-means)*: K кластеров (2–64, по умолчанию 16), каждый кластер
    привязывается к реальному блоку — гарантированно ≤ K типов блоков.
  - *Полная палитра*: каждый пиксель → ближайший блок из палитры 81 блок
    (16 шерстей + 16 бетонов + 17 терракот + 32 дополнительных).
- **Ориентация**: вертикальная картина (X-Y, глубина 1) или ковёр на полу
  (X-Z, высота 1).
- **Дизеринг (Floyd–Steinberg)**: опционально, для фото и градиентов —
  размазывает ошибку квантования в высокие частоты и убирает бандинг.
  В адаптивном режиме кандидаты — только выбранные ≤ K блоков (гарантия K
  сохраняется), в режиме полной палитры — все 81 блок.
- **Рельеф (3D)**: яркость → глубина/высота (сглаживание, инверсия), цветная
  поверхность из того же квантования, основание — выбранный блок, пустоты — air.
  Вертикальная картина становится барельефом (рельеф вглубь), ковёр — террейном
  (рельеф вверх). Превью — затенённая проекция.
- **Превью**: сетка блоков, легенда со счётчиками, инспектор блока под курсором.
- **Экспорт .litematic**: gzip-NBT, LSB-first упаковка BlockStates,
  PNG-миниатюра (PreviewImageData), детерминированная генерация
  (превью == файл).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```

Открыть http://127.0.0.1:5000 (при первом запуске разрешить доступ в брандмауэре
для локальной сети не обязательно — сервер слушает только localhost).

## Как загрузить схему в Minecraft

1. Скачать `.litematic` из приложения.
2. Положить в `%APPDATA%\.minecraft\schematics\`.
3. В игре (с модом Litematica): `M` → Load Schematics → выбрать файл,
   вставить в мир (`M` → Schematic Placements → Load → ... ).

## Тесты

```bash
.venv\Scripts\python -m pytest
```

Round-trip тесты проверяют записанный NBT независимым декодером (включая
упаковку BlockStates для размеров палитры 1–129 и порядок индексов x→z→y),
плюс перекрёстная проверка библиотекой nbtlib (если установлена).

## Ограничения

- Полупрозрачные пиксели композитируются на белый фон.
- Картинки меньше целевого размера не увеличиваются (пиксели не выдумываются).
- Часть палитры (deepslate, copper, amethyst) требует Minecraft ≥ 1.17;
  остальные имена блоков — 1.13+.
- 2D-схема заполнена блоками целиком (без воздуха), толщина 1 блок.
